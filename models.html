Task Guide

Quick Picks by Task Type

Start with the cheapest model that can do the job, then escalate only when the task is ambiguous or risky.

Small code edits

Start: GPT-5 mini for fixed Python/API collection and known-schema edits.

Escalate: GPT-5.6 Luna for cheap iteration when the edit needs another pass.

Feature implementation

Start: GPT-5.6 Terra for bounded validation gates around requirements, evidence, and tests.

Escalate: GPT-5.6 Sol for multipart orchestration while promotional pricing is active.

Debugging production issues

Start: GPT-5.6 Terra to verify logs, citations, repro evidence, and claim quality.

Escalate: GPT-5.6 Sol for long diagnosis, then Claude Opus 5 only if the issue remains unresolved.

Large refactors

Start: GPT-5.6 Sol for long multipart planning and cross-file coordination during promotional pricing.

Escalate: Claude Opus 5 for exceptional high-consequence review after cheaper routes fail.

Code review

Start: GPT-5.6 Terra for citation-backed evidence gates and focused diff checks.

Escalate: Claude Opus 5 for high-risk logic, security-sensitive areas, or architecture drift.

Docs and explanations

Start: GPT-5 mini for source collection and first drafts from known evidence.

Escalate: Claude Sonnet 5 only when blind review shows it improves audience-fit communication.

Visual or UI reasoning

Start: GPT-5.6 Terra when the work is bounded by screenshots, requirements, or citations.

Escalate: GPT-5.6 Sol or Claude Opus 5 when layout, product behavior, and code changes all interact.

Budget-sensitive loops

Start: GPT-5 mini or GPT-5.6 Luna before using Terra, Sol, Sonnet 5, or Opus 5.

Escalate: Spend higher token-rate models only after the question, evidence, and acceptance criteria are narrowed.

Recommended Flows

How to Chain Models

Use different models for different phases instead of trying to make one model do every job.

Complex feature flow

  1. Collect with GPT-5 mini: gather fixed Python/API evidence and known-schema inputs.
  2. Validate with GPT-5.6 Terra: check citations, extraction quality, and acceptance criteria before writing.
  3. Orchestrate with GPT-5.6 Sol: coordinate long multipart implementation or diagnosis while promotional pricing is active.
  4. Escalate only if needed: use Claude Sonnet 5 for blind-tested communication quality or Claude Opus 5 for exceptional unresolved risk.

Bug triage flow

  1. Summarize with GPT-5 mini: collect symptoms, logs, repro steps, and suspected areas.
  2. Verify with GPT-5.6 Terra: test whether the evidence supports the likely cause.
  3. Diagnose with GPT-5.6 Sol: handle long cross-system reasoning while the promotional rate applies.
  4. Escalate with Claude Opus 5: reserve for unresolved or high-consequence failures.

Large refactor flow

  1. Inventory with GPT-5 mini: find call sites, dependencies, and duplicate patterns.
  2. Gate with GPT-5.6 Terra: validate the evidence behind each migration claim.
  3. Coordinate with GPT-5.6 Sol: manage long multipart sequencing while promotional pricing is active.
  4. Audit with Claude Opus 5: use a final pass only on the risky diff and tests.

Low-cost daily flow

  1. Collect with GPT-5 mini: keep fixed-source work on the lowest simple route.
  2. Iterate with GPT-5.6 Luna: use it for cheap checks when the task is still small.
  3. Validate with GPT-5.6 Terra: spend more only when evidence quality matters.
  4. Escalate deliberately: reserve GPT-5.6 Sol, Claude Sonnet 5, and Claude Opus 5 for their defined routes.

Cost Notes

How to Think About Cost

Copilot Enterprise usage is token-based. The real cost depends on prompt length, cached context, cache writes where applicable, outputs, selected model, and agent surface.

Use included models first

GPT-5 mini and GPT-5.6 Luna are the safest starting points for routine prompts because their Enterprise token rates are low. GPT-4.1 should be treated as a migration-only option.

Treat mid-tier rates as workhorse capacity

GPT-5.6 Terra and Claude Sonnet 5 sit in the middle of this six-model route, but they serve different jobs: Terra for evidence gates, Sonnet 5 only for blind-tested communication quality.

Reserve premium-heavy models

GPT-5.6 Sol and Claude Opus 5 should answer narrow, high-value questions rather than carrying every iteration of a long coding session. Re-check Sol after the September 3, 2026 promotion expires.
